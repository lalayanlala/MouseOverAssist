■ ビルド手順
1. ZIPを右クリックして「すべて展開」します。旧版フォルダへ上書きしないでください。
2. BUILD.bat をダブルクリックします。
3. SUCCESS と上記の Warning gate OK が出れば、警告0でビルド完了です。
4. GitHub配布用ファイルを作る場合は PREPARE_REPOSITORY.bat を実行します。
5. リポジトリURLには次を入力します。
   https://github.com/lalayanlala/MouseOverAssist
6. Release フォルダの UPLOAD_STEPS.txt の案内に従います。

■ 必要な環境
.NET 10 SDK (x64)。Runtimeだけではビルドできません。
https://dotnet.microsoft.com/download/dotnet/10.0
Dalamud API 15。XIVLauncherからゲームを一度起動しておきます。
